## Tweet 2 (The Problem)

Before DarkDrop, Solana confidential transfers required:

❌ Rust CLI tools (technical users only)
❌ Server-side computation (privacy leak)
❌ Native apps (installation friction)

This made privacy inaccessible to most users.

We changed that. (2/7)

---

## Tweet 3 (The Solution)

We compiled Solana's `solana-zk-sdk` (Rust) to WebAssembly and integrated it into a web app.

Now ANYONE can generate:
✅ Equality Proofs
✅ Validity Proofs  
✅ Range Proofs

All three ZK proofs. All in the browser. (3/7)

---

## Tweet 4 (The Tech)

The stack:
• Rust: solana-zk-sdk + curve25519-dalek
• WASM: wasm-pack compilation
• Workers: Non-blocking computation
• TypeScript: Clean integration
• React: Modern UI

Real ElGamal encryption + Pedersen commitments running client-side! (4/7)
